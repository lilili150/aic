# 后续优化建议

## 已确认的问题

首轮最佳 mIoU 为 `0.74514`，但类别表现不均衡：`Barren` 为 `0.53340`，`Background` 为 `0.66254`，`Vehicle` 为 `0.71723`。因此下一步重点应放在困难类别、类别不均衡和小目标，而不是继续盲目增加 epoch。

## 推荐实验顺序

1. **轻度颜色增强**：改变亮度、对比度、饱和度，只作用于 RGB 图像，mask 不做颜色变换。它对不同光照条件可能有帮助，风险低。
2. **CrossEntropy + Dice Loss**：改善小面积类别和边界区域，优先观察 `Barren`、`Vehicle`、`Agricultural`。
3. **类别加权 CrossEntropy**：依据训练集像素分布设置有限权重，避免模型过度偏向大面积类别。权重不能过激，否则 Background 可能下降。
4. **提高输入尺寸**：比较 `512` 和 `768`，重点观察 Vehicle 边界和小目标；同时记录速度和显存。
5. **学习率和训练轮数**：当前第 25 轮后已平台期，可尝试学习率衰减，而不是单纯把 epoch 从 30 增到更大。

所有实验必须沿用相同的 train/validation 划分，并保留每个实验目录。评价时同时看总 mIoU 和每类 IoU，不能只看困难类别而忽视总体分数。

## 不建议马上做的事

暂时不建议同时加入多种增强、复杂网络结构、Focal Loss、Dice、类别权重和更大输入。这样即使分数变化，也无法判断是哪一项造成的。
