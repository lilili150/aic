## 判断

1. loss 从 0.85962 降到 0.26595，训练链路正常，模型学到了有效特征。
2. mIoU 从 0.61080 提升到 0.74514，基线已经具备较强效果。
3. 第 25～30 轮在 0.735～0.745 之间波动，已经进入平台期；推理应使用第 25 轮最佳 checkpoint，而不是默认使用最后一轮。
4. `Barren` 是最明显的短板，其次是 `Background` 和 `Vehicle`。这三个类别优先作为改进实验的观察对象。

## 下一步实验建议

第一组建议只加入轻度颜色增强，保持模型、学习率、划分和 epoch 不变。第二组再尝试 `CrossEntropy + Dice Loss`，重点观察 `Barren` 和 `Vehicle` 是否提升。每次只改变一个主要因素，只有总 mIoU 提升或在关键类别上取得有价值的改善时才保留。
