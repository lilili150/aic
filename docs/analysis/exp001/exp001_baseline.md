## 判断

1. loss 从 0.85962 降到 0.26595，训练链路正常，模型学到了有效特征。
2. Ignore 修复后 mIoU 为 0.74939，比旧口径高 0.00425；旧指标应保留作审计对照，正式比较统一使用修复后口径。
3. epoch 25 仍是当前可用的最佳 checkpoint；修复评价逻辑没有改变模型权重。
4. 正式基线下 `Barren` 仍是最低类别，其次是 `Vehicle` 和 `Background`。后续实验重点观察这三类，同时不能牺牲总体 mIoU。

## 划分审计结果

审计报告：`outputs/audits/split_audit_report.json`。

- 训练集 5597 张，验证集 1399 张。
- train/validation 没有重复 ID，训练集和验证集内部也没有重复 ID。
- 跨集合图片 SHA-256 重复数为 0，未发现完全相同的图片泄漏。
- 图片、mask 缺失或损坏数为 0，尺寸检查错误数为 0。
- 跨集合有 1 个完全相同的 mask：训练样本 `2018` 与验证样本 `4470`。对应图片并不相同，暂不视为数据泄漏；后续可人工复核这对样本。
- 类别像素比例最大差异为 Road `+1.05` 个百分点，Building `-0.63` 个百分点，属于当前随机划分下可接受的差异。

结论：固定划分通过精确重复和基础分布审计，可以用于 `exp002`。本报告没有进行感知哈希或特征级近重复检查，因此仍不宣称排除了所有近重复风险。
